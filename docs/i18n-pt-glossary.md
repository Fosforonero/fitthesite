# Glossário PT-BR canônico — FitMesh Sync (tradução do site)

> Contrato de qualidade para a tradução em português do Brasil. TODA superfície
> (dicionário, páginas, artigos) deve respeitá-lo para manter coerência. Português
> **do Brasil** (você informal, sem "vós", sem regionalismos excessivos), registro
> técnico-claro, profissional, acolhedor. `og:locale` = `pt_BR`.

## Regras não negociáveis (de CLAUDE.md)
- **Nada de em-dash (—)** na prosa: use ponto, vírgula, dois-pontos, parênteses.
  (Exceção: `—` como "dado não disponível" em tabelas.)
- **Nada de jargão técnico** voltado ao usuário (sem "idempotente", "anti-loop",
  nomes de API, arquiteturas internas). Explique as FUNCIONALIDADES e COMO USÁ-LAS.
- **YMYL-safe**: nenhuma alegação médica. Proibidos: "grau médico", "diagnóstico",
  "clínico", "cura/trata + doença", "previne + doença". Use: "ajuda você a
  acompanhar", "apoia seus hábitos de bem-estar". FitMesh não é um dispositivo médico.
- **Nada de nomes de concorrentes diretos.** Termos genéricos: "apps que conectam
  ecossistemas de saúde". (Health Connect / HealthKit / Samsung Health = padrões/
  apps first-party, podem ser citados.)
- **Tom profissional, nunca depreciativo** em relação a outros apps.

## Entidades canônicas — NÃO traduzir (forma exata)
- **FitMesh Sync** (app, sempre "FitMesh Sync") · **FitMesh.fit** (domínio)
- **Mesh Família** → em PT-BR: **Mesh Família** (mantém o nome original da feature)
- **Fosforonero** (estúdio) · **Matteo Pizzi** (fundador)
- **Health Connect** · **HealthKit** · **Galaxy Watch** · **Wear OS** · **Google Play** · **App Store**

## Termos-chave IT/EN → PT-BR (usar SEMPRE estes)
- smartwatch → smartwatch · wearable → wearable (ou "dispositivo")
- dashboard → painel · dispositivi → dispositivos
- passi → passos · distanza → distância
- battito / frequenza cardiaca → frequência cardíaca · battito a riposo → frequência cardíaca em repouso
- sonno → sono · fasi del sonno → fases do sono · profondo/REM/leggero → profundo/REM/leve
- calorie attive/basali → calorias ativas/basais · allenamenti → treinos
- recupero → recuperação · trend → tendências · passi e calorie → passos e calorias
- sincronizzazione → sincronização · sincronizzare → sincronizar
- dati di salute → dados de saúde · privacy → privacidade · in background → em segundo plano
- anello (smart) → anel (inteligente) · orologio → relógio
- anziani → pessoas idosas · caregiver → cuidadores · gruppo famiglia → grupo familiar
- acquisto unico → compra única · gratis → grátis · scarica → baixe
- impostazioni → configurações · account → conta · accedi → entrar
- in arrivo → em breve · disponibile → disponível
- "I tuoi dati non sono un prodotto" → "Seus dados de saúde não são um produto"

## SEO/GEO
- Slugs PT-BR dedicados, kebab-case, em português, keyword-first (exemplos:
  `sincronizar-smartwatch`, `exportar-dados-garmin`, `como-funciona-health-connect`).
- Meta description PT-BR de 140-160 caracteres, natural, com a keyword.
- hreflang: it/en/pt-BR + x-default=it. `og:locale` pt_BR.
- Sem keyword stuffing; português que soe escrito por falante nativo.
